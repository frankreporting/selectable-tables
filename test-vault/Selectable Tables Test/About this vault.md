# About this vault

Invented notes for testing Selectable Tables by hand. Each note matches a section of the test plan.

- [[Two report tables]]: passing, selecting, Enter, Escape, copy and delete.
- [[Table first]] and [[Table last]]: a table at the very start or end of a note.
- [[Properties then table]]: a table directly below the properties.
- [[Edge cases]]: wrapped lines next to a table, a callout and a list holding tables, two tables close together.
- [[Images and tables]]: an image right above and right below a table.
- [[Markdown in cells]]: tables whose first cells hold links, bold, code and tags, which cost the most to open; for the speed numbers.
- [[Cell moves]]: moving between cells: a table with Markdown in its cells, uneven rows, a wide table and a tall one.
- [[Frozen tables]]: frozen rows and columns, on tall, wide tables with and without a mark.
- [[Long note]]: only for the speed numbers.

Run `npm run test-vault` in the repo to build the plugin and copy it in.
